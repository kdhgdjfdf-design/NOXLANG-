# NOX LANG

تطبيق ويب تجريبي لتعلّم الفرنسية، بواجهة عربية بسيطة.

## الأقسام
- **التعلّم:** دروس A1 أولية في التحية، أدوات التعريف، الأفعال، والماضي.
- **النطق والاستماع:** تشغيل النطق الفرنسي عبر أصوات الجهاز، مع تمارين تمييز أصوات.
- **المحادثة:** مواقف نصية موجّهة مع أمثلة للرد.
- **الاستماع والبودكاست:** مقاطع قصيرة مولّدة من النص عبر تحويل النص إلى كلام، مع أسئلة فهم.
- **الدراسة والكتابة:** وصف صورة، كتابة قصة، قواعد، وملاحظات إرشادية على النص.
- **تقدّمي:** حالة الدروس والمحاولات، محفوظة محليًا.

## تشغيله
افتح `index.html` في متصفح حديث. لتجربة الميكروفون، استخدم HTTPS (مثل GitHub Pages) وامنح المتصفح إذن الميكروفون.

## نشر GitHub Pages
1. افتح **Settings → Pages**.
2. في **Build and deployment** اختر **Deploy from a branch**.
3. اختر الفرع **main** والمجلد **/(root)** ثم اضغط **Save**.
4. انتظر حتى يظهر رابط النشر في صفحة Pages.

## حدود النسخة الحالية
- تستخدم قراءة النصوص صوتًا فرنسيًا متاحًا على الجهاز؛ توفر وجودة الصوت يختلفان حسب الجهاز والمتصفح.
- الميكروفون يسجل الصوت محليًا لإعادة الاستماع، ولا يقيّم مخارج الحروف تلقائيًا.
- المحادثات والتصحيحات إرشادية محلية وليست نموذج ذكاء اصطناعي متصلًا.
- التقدم محفوظ في تخزين المتصفح على الجهاز نفسه.
- هذه نسخة أولية قابلة للاختبار، وليست بعدُ تطبيقًا مكتملًا بكل مستويات الفرنسية.

## الخصوصية
لا يرسل التطبيق التسجيلات الصوتية إلى خادم. تجنب إدخال معلومات شخصية في التمارين.
